# 基于 SpringBoot + Vue 的商品进销存系统 (Product Invoicing & Inventory System)

采购管理 · 销售订单 · 库存管控 · 仓储管理 · 数据统计 · 供应商管理 · 物流跟踪 · 在线支付 · 多角色协同

本项目是一套面向中小企业的商品进销存全流程管理系统，采用前后端分离架构，覆盖**管理员**与**普通用户（客户/采购员）**两类角色。系统围绕"商品管理、采购供应、销售订单、库存管控、仓储管理、物流配送、数据统计、客户管理、员工管理"等核心业务设计，支持从商品采购入库、销售订单处理、库存实时监控、仓储管理、物流配送跟踪到财务缴费、订单评价的全链路数字化管理，实现进销存业务闭环、库存预警自动化、数据可视化分析，适用于批发零售企业、连锁门店、电商仓储、贸易公司等场景。

## 核心特性

- **全流程进销存闭环**：覆盖"采购→入库→库存→销售→出库→物流→收款→评价"完整业务链路，支持采购申请、采购下单、入库验收、销售订单、发货配送、在线支付、订单评价全流程管理。
- **多仓库库存管理**：支持多仓库/多库区管理，实时展示各仓库商品库存数量，支持库存调拨、库存盘点、库存预警（低于安全库存自动提醒），库存表以（仓库ID, 商品ID）为联合唯一索引防止数据重复。
- **采购与供应商管理**：管理供应商档案（名称、联系人、联系方式、资质、合作状态），支持商品采购申请、采购单生成、采购物流跟踪、采购入库验收，支持按供应商统计采购历史与应付账款。
- **销售订单管理**：客户可在线浏览商品、下单采购、选择配送地址、在线支付，管理员处理订单（确认/发货/完成），支持订单详情查看、订单状态跟踪、订单评价。
- **物流信息管理**：集成物流跟踪功能，支持录入物流单号、查看物流轨迹，管理员可管理物流信息，用户可在订单详情中实时查看配送进度。
- **库存预警**：设置商品安全库存阈值，当库存低于预警值时自动触发提醒，支持按仓库/商品分类查看预警列表，辅助采购决策。
- **数据统计与可视化**：多维度数据统计看板，包括销售统计（销售额/订单数/客单价趋势）、销售排行（热销商品TOP10）、库存统计、采购统计、财务统计，支持图表可视化展示与报表导出。
- **在线支付与缴费记录**：支持集成支付宝/微信支付接口，用户下单后可在线支付，系统自动记录缴费记录，管理员可查看缴费明细与财务对账。

## 功能模块概览

## 管理员端

管理员拥有系统最高权限，负责平台全部业务的配置与管理：

### 基础数据管理

- **商品管理**：管理商品主数据，包括商品编码（唯一索引）、名称、分类、规格型号、品牌、单位、进价、售价、安全库存、商品图片、商品状态（上架/下架），支持批量导入/导出商品。
- **仓库管理**：管理仓库/库房信息，包括仓库编号、名称、地址、容量、负责人、联系方式、仓库状态，支持多仓库管理与库区划分。
- **供应商管理**：管理供应商档案，包括供应商名称、行业类别、联系人、联系方式、地址、资质文件、合作状态、历史评价、应付账款，支持供应商评级。
- **客户管理**：管理客户档案，包括客户名称、类型（个人/企业）、联系人、联系方式、地址、信用等级、历史订单数、累计消费金额，支持客户分组与标签管理。
- **员工管理**：管理系统员工信息，包括姓名、工号、岗位、所属部门、手机号、角色权限、账户状态，支持员工账号启用/禁用与操作日志查看。
- **管理员管理**：管理超级管理员与子管理员账号，包括用户名、姓名、角色、权限范围、最后登录时间，支持新增/编辑/删除管理员。

### 采购与供应管理

- **供应采购**：查看采购业务总览，包括待采购、采购中、已完成的采购单统计，支持采购趋势分析与供应商采购占比统计。
- **商品采购**：新建采购单，关联供应商、采购商品明细（商品、数量、单价、金额）、预计到货时间、采购备注，采购状态包括待采购/采购中/已发货/已完成/已取消。
- **商品申请**：处理内部或客户提交的商品采购申请，查看申请详情（申请人、申请商品、数量、用途、期望时间），执行审批操作（通过/驳回），审批通过后自动生成采购单。
- **采购物流**：管理采购物流信息，录入采购单关联的物流单号、物流公司、发货时间，跟踪采购商品在途状态，到货后触发入库提醒。

### 销售与订单管理

- **订单信息**：查看所有销售订单列表，包括订单号、客户、下单时间、商品明细、订单金额、订单状态（待付款/待发货/已发货/已完成/已取消/已退款），支持订单筛选与批量操作。
- **订单详情**：查看订单完整信息，包括客户信息、商品明细、支付信息、物流信息、订单操作日志，支持订单备注与异常处理。
- **订单评价**：查看客户对已完成订单的评价内容、评分、评价图片，支持评价回复与差评处理，评价数据用于商品与服务质量分析。
- **缴费记录**：查看所有订单的缴费记录，包括订单号、支付金额、支付方式（支付宝/微信/银行卡）、支付时间、支付状态，支持财务对账与导出。

### 仓储与库存管理

- **仓库库存**：查看各仓库的商品库存明细，包括商品名称、规格、当前库存、安全库存、库存状态（正常/预警/缺货），支持按仓库/商品分类筛选。
- **库存统计**：多维度库存统计分析，包括库存总量、库存金额、库存周转率、滞销商品统计、库存预警商品列表，支持库存报表导出。
- **库房预警**：实时展示库存预警信息，包括低于安全库存的商品、临期商品、滞销商品，支持预警阈值配置与预警消息推送。
- **物流信息**：管理销售订单的物流信息，录入物流单号、物流公司、发货时间，支持物流轨迹查询与异常物流处理。

### 运营与统计

- **公告管理**：发布系统公告，包括促销通知、规则变更、系统维护、新品上架等，支持置顶、定时发布、富文本编辑。
- **销售统计**：多维度销售数据分析，包括销售额趋势（日/周/月/年）、订单数趋势、客单价分析、新老客户占比、支付方式分布，支持图表可视化。
- **销售排行**：展示热销商品TOP10、热销分类TOP5、高客单价商品排行、复购率最高商品排行，辅助选品与营销策略制定。
- **数据统计**：综合数据看板，展示核心经营指标（今日销售额/订单数/新增客户/库存预警数），支持自定义时间范围与数据导出。

## 用户端

普通用户（客户/采购员）为系统的商品采购方，提供完整的采购与订单管理功能：

### 账号与个人

- **账户注册登录**：支持手机号+验证码注册登录、账号密码登录，支持找回密码、个人信息编辑（昵称、头像、联系方式、收货地址管理）。
- **我的信息**：查看与编辑个人基本信息，包括姓名、手机号、邮箱、默认收货地址、发票信息，支持修改密码与安全设置。

### 商品与采购

- **商品采购**：浏览可采购商品列表，支持按分类/品牌/关键词搜索，查看商品详情（图片、规格、价格、库存、描述），选择商品与数量加入购物车，支持批量下单。
- **商品申请**：提交商品采购申请，填写申请商品、数量、用途说明、期望到货时间，提交后等待管理员审批，审批通过后生成采购单并通知用户。

### 订单与支付

- **我的订单**：查看本人所有订单，包括订单号、商品明细、订单金额、订单状态、下单时间，支持订单筛选（待付款/待发货/已发货/已完成），支持取消待付款订单与申请退款。
- **在线支付**：对待付款订单进行在线支付，支持支付宝、微信支付、银行卡支付等多种支付方式，支付成功后自动更新订单状态。
- **缴费记录**：查看本人所有缴费记录，包括订单号、支付金额、支付方式、支付时间、支付状态，支持下载支付凭证。

### 评价与互动

- **订单评价**：对已完成订单进行评价，包括商品评分（1-5星）、服务评分、评价内容、评价图片，评价提交后不可修改，支持查看历史评价记录。
